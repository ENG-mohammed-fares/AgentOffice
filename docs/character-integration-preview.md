# Character integration preview
This branch is based on the latest experimental renderer branch, not a release. Copy the exact seven candidate GLBs and manifest.json from the prepared ZIP's models directory into assets/agile-office/characters, then commit them on this branch. The build validates every file SHA-256 and the ten named clips before copying into app/public/office/characters. Missing directory intentionally preserves the previous office; partial or modified assets fail the build. The character layer loads after the first office frame. Skeletons are not passed into static batching. The animation loop limits idle rendering to about 30 fps and pauses with page visibility. No dynamic avatar shadows yet. Preview placement is standing behind the chairs; exact seating, IK, collision avoidance, and GPU validation remain required. AI Engineer visually occupies station 2 as a temporary preview, without changing the Software Architect task role or assigning its tasks to AI Engineer. Local task status and demo activity can drive named clips on matching roles; real agent execution is not connected. The existing PBR default remains unchanged; the baked and Full HD assets are separately generated candidates, not automatically adopted. Do not merge/publish until assets are committed, tests pass, and the visual/GPU review is complete.
